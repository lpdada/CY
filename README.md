# 畅言（CY）

无需开发者账号、免费自签就能装的语音转写 App，带一个能真正打中文的拼音九宫格键盘。

本仓库是 `n0an/VivaDicta` 3.12.1 的复刻（MIT 协议，上游版权不变），加上一组为自签环境做的自有功能。主 App 与键盘的显示名均为「畅言」。

> 本仓库是私有复刻，不上架 App Store。安装包是未签名的 IPA，用 Sideloadly + 免费 Apple ID 安装，7 天过期需重签。

## 本仓库自有的功能

### 拼音九宫格：一个真正的中文输入法

- **T9 九宫格**：数字键打拼音，不用切到系统键盘。
- **真词库**：内置 3 万常用词（2–4 字），词候选按词频排序，不再是单字拼凑。
- **全部切分**：数字串会被切成所有可能的音节组合再查词，歧义输入（如 9426）会同时给出多个词候选，按词频排。
- **组字串**：首选候选以 marked text 显示在输入框里，像正常输入法一样能看到正在组字的词。
- **候选换页**：每页 6 个，点「换页」翻页，末页点「首页」回到第一页。
- **符号页**：^^ 键切出 9 个常用标点；左下角「英文」键切回英文键盘。

### 没有 App Group 也能听写（畅言桥）

免费签名拿不到原 App Group，键盘听写的「指令—状态—结果」全链会断。本仓库换了一套不依赖 App Group 的桥：

- 事件信号走系统级 Darwin 通知；
- 键盘→主 App 的载荷走命名剪贴板；
- 主 App→键盘的结果走本地 HTTP（`127.0.0.1:47821` 的结果槽 + `/vd/result`），不再只靠剪贴板跨进程传递——这是修「微信里听写有记录但输入框不回插」的关键。

### 思考开关：关了就真的不思考

设置 → AI 设置 →「让模型思考」。关掉时，不仅写死名单内的模型会降档，名单外的 deepseek / glm / kimi / moonshot 也会补发 `thinking.type=disabled`。做这个 App 的起因就是润色太慢、怀疑模型开了思考，开关关不严等于没做。

### 界面中文化

设置与主界面译为简体中文（给 AI 模型看的内部描述与服务商名保留英文）。

### 自签瘦身

打包时剔除 Watch / Widget / 分享 / 操作扩展，只留主 App + 键盘，约 40MB，免费账号可以直接签装。

## 安装

1. 下载最新 release 里的 `VivaDicta-unsigned.ipa`。
2. 用 [Sideloadly](https://sideloadly.io/) + 免费 Apple ID 安装。
3. 7 天过期后重签一次即可。

注意：

- 键盘需要「完全访问权限」（`RequestsOpenAccess`），否则桥的本地通信与剪贴板通道不可用。
- 自签环境下不可用：iCloud 同步、推送通知。
- 本地转写模型（Parakeet / Whisper）在 HuggingFace 上，国内网络下 App 内下载可能失败；云端转写不受影响。

## 使用

1. 主 App 里填好转写与 AI 服务的 Key。
2. 设置 → 通用 → 键盘 → 添加「畅言」，并打开「允许完全访问」。
3. 任意输入框里切到畅言键盘：点话筒听写，或直接用九宫格打拼音。
